# FORGE — Cursor 3D capability lab

A tiny interactive demo of what you can build with Cursor in 3D:

- Procedural shapes
- PNG → 3D relief mesh
- PBR / stylized materials
- Motion / turntable presentation
- One-click GLB export

## Run

```bash
cd capability-lab
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — local playground
- `npm run build` — production build
- `npm run preview` — preview the build
